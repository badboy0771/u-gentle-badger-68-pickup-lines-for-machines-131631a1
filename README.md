## How it works

`main.ts` (Node 22) writes the line — exactly 77 characters, one line, no
trailing newline — to `/output/entry.txt`, after validating it against the
bounty gate (1–200 characters, not only whitespace, single line).

Run it from any directory:

```sh
node main.ts
```
